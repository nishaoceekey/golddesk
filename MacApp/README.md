# GoldDesk for Mac

GoldDesk is a Mac-only workspace launcher for the official ChatGPT and TradingView desktop apps.

- Opens the installed ChatGPT/Codex desktop app using its existing login.
- Opens the installed TradingView desktop app with OANDA:XAUUSD on the 15-minute chart using its existing login.
- Arranges ChatGPT on the left and TradingView on the right.
- Includes a starter instruction for safe chart-drawing requests with Computer Use.
- Does not embed either website and does not require a second web login.
- Never places, closes, or modifies live or demo trades.

## First launch

Click **Open Trading Workspace**. macOS may ask for Accessibility permission so GoldDesk can resize and position the two app windows. Grant the permission in System Settings, return to GoldDesk, and click **Arrange Again**. GoldDesk uses this permission only for window arrangement.

## Example request

`@Computer mark the nearest major BUY and SELL zones on OANDA:XAUUSD 15m. Manage only drawings labelled AUTO ZONE. Never place, close, or modify any trade.`
